# hope_connected_projeto_integrador
Este é o repositório do projeto Hope Connected, uma solução tecnológica elaborada pelos alunos do IMT - Instituto Mauá de Tecnologia em parceria com o instituto AACD (Associação de Assistência à Criança Deficiente), com o foco de desenvolver uma aplicação web voltada para a solicitação de serviços para outros institutos voluntários.
